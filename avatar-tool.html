Then put it live

  1. Save the downloaded file into the assets/ folder, keeping the name avatar.jpg.
  2. Commit and push it: git add assets/avatar.jpg && git commit -m "add profile photo" && git push
  3. That is all — the site finds the file on its own and uses it in the nav mark, the recruiter snapshot and the reading rail. No HTML to edit.
  4. To go back to the ME monogram, delete the file and push again.
