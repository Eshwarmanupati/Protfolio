Since March 2026 I have been working remotely at Agiledigest Consulting as a manual test engineer and developer. Testing other people’s code every day changed how I write my own: I think about edge cases earlier, keep state easier to reason about, and write commits a reviewer can actually follow.

How I work

Four habits I actually keep

01

Ship, then refine

Get a working slice in front of someone early, then improve it with feedback instead of guessing.

02

Test before I demo

Habit from the internship: walk the unhappy paths first, so the demo never dies on an empty state.

03

One problem a day

A DSA problem most days keeps the fundamentals sharp without it becoming a separate project.

04

Write it down

READMEs, defect reports, commit messages — if the next person cannot follow it, it is not done.
